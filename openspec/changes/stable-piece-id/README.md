# stable-piece-id

Una pieza tiene una identidad propia que sobrevive a moverla, renombrarla y
reorganizar la carpeta. Hoy su identidad **es su ruta**, y la ruta cambia: una sola
reorganización del vault dejó 57 filas del tablero apuntando al vacío.

Es el cuello de botella de `move-resilient-keys` y de D-15. Un pase de script sobre
~265 archivos, una vez.
